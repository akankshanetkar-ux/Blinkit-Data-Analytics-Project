# BlinkIT Data Analytics Project

This repository contains my Data Analytics mini project based on BlinkIT grocery sales data.

The project demonstrates data analysis, SQL queries, Excel dashboards, Power BI visualization, Tableau visualization, and Python-based data analysis.

## Project Overview

The objective of this project is to analyze BlinkIT grocery sales data and identify useful business insights related to sales, outlets, products, locations, ratings, and other key attributes.

## Tools & Technologies

* Python
* Jupyter Notebook
* Pandas
* SQL
* Microsoft Excel
* Power BI
* Tableau

## Project Components

### 01. Python Data Analysis

Python and Pandas are used for data exploration, cleaning, analysis, and deriving insights from the BlinkIT dataset.

### 02. SQL Analysis

SQL queries are used to retrieve and analyze information from the BlinkIT sales dataset.

### 03. Excel Dashboard

Interactive Excel dashboards are created to visualize important sales and business metrics.

### 04. Power BI Dashboard

A Power BI dashboard is developed to provide interactive visual analysis of BlinkIT grocery sales data.

### 05. Tableau Dashboard

A Tableau workbook is included for interactive data visualization and business analysis.

## Dataset

The project uses a BlinkIT grocery sales dataset containing information related to products, outlets, sales, ratings, locations, and other attributes.
